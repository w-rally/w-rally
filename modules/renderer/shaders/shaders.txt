# Every shader the renderer loads (core/shaders.h LoadShader), compiled at build time by ngg-shaderc into WRenderer.dll.
# One line each: <file> <entry point> <profile> [compiler arguments, as DXC takes them]. The line is the key LoadShader
# looks the shader up by - the arguments in the order the C++ passes them. Profiles *_5_x compile with FXC (DXBC),
# *_6_x with DXC (DXIL, signed). A shader missing here fails to load in a shipped build; with NGG_SHADER_DIR set it
# compiles anyway and the log says it is not listed. docs/ngg-design.md, "Shaders and the pipeline cache".
